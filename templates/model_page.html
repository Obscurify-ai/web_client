API

The OpenAI-compatible API works for any account with a balance, with the same prices and plan rules as the chat. Get an API key from the account page.

curl https://obscurify.ai/v1/chat/completions \
  -H "Authorization: Bearer $OBSCURIFY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{ model.id }}", "messages": [{"role": "user", "content": "Hello"}]}'
from openai import OpenAI

client = OpenAI(base_url="https://obscurify.ai/v1", api_key="sk-obs1_...")
reply = client.chat.completions.create(
    model="{{ model.id }}",
    messages=[{"role": "user", "content": "Hello"}],
)
print(reply.choices[0].message.content)
