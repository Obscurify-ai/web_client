Using the API? Run the private-sessions proxy.

The chat and the Android app use private sessions: we can't tell which chats belong to which account. Requests sent with your API key don't get that by themselves; they are tied to your account. To make API and agent requests unlinkable, run our open-source proxy (or our MCP server in private mode) and point your tools at it.
